# Bank-Deposit-Prediction-ML
Machine learning classification project to predict whether a customer will subscribe to a bank term deposit using KNN, Naive Bayes, and Decision Tree algorithms, with performance evaluation and GridSearchCV hyperparameter tuning.
# Bank Deposit Prediction using Machine Learning

## Project Overview

This project uses machine learning classification algorithms to predict whether a customer will subscribe to a bank term deposit.

## Algorithms Used

- K-Nearest Neighbors (KNN)
- Bernoulli Naive Bayes
- Decision Tree

## Techniques Used

- Data preprocessing
- Label Encoding
- Feature Scaling
- Train-Test Split
- Confusion Matrix
- Accuracy
- Precision
- Recall
- F1 Score
- GridSearchCV
- Hyperparameter Tuning

## Hyperparameter Tuning

GridSearchCV was used to find the best KNN parameters.

Best parameters:
- n_neighbors = 11
- weights = distance
